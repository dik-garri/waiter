# 🍽️ Официант — симулятор ресторана

2D-игра в браузере: ты официант в ресторане.

**Играть:** https://dik-garri.github.io/waiter/

## Игровой цикл

1. 👋 Встреть гостей у входа и проводи их за свободный стол
2. ✋ Прими заказ, когда гости выберут блюда
3. 🛎️ Отнеси заказ на раздачу — повар начнёт готовить
4. 🍔 Забери готовое блюдо и принеси его к нужному столу
5. 🍽️ Убери грязную посуду и отнеси её в мойку
6. 💳 Получи оплату и чаевые (чем довольнее гости — тем больше чаевые)

Смена длится с 12:00 до 22:00 (3 минуты). Выполни дневную цель по выручке,
чтобы перейти на следующий день. Между днями покупай улучшения: кроссовки,
опытного повара, живую музыку, красивое меню, большой поднос и новые столы.
С каждым днём гостей больше, компании крупнее, а в меню появляются новые блюда.

## Управление

- `WASD` / стрелки — ходить
- `E` / `Пробел` — действие рядом
- Клик / тап по объекту — официант сам подойдёт и сделает действие
- `Esc` — пауза

## Технологии

Чистые HTML + CSS + JavaScript (Canvas 2D, WebAudio), без сборки и зависимостей.
Прогресс сохраняется в `localStorage`.

Запуск локально: `python3 -m http.server` и открыть http://localhost:8000
